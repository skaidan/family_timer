# Roadmap de iteración

## Fase 1: hacer la experiencia más útil

1. Conectar con Google Calendar para importar eventos.
2. Normalizar eventos a categorías visuales con reglas simples.
3. Mostrar el tiempo restante de la actividad actual en formato visual y textual.
4. Permitir marcar una actividad como "en curso" o "terminada" desde la interfaz.
5. Añadir una vista de tiempo libre entre bloques para que sea más evidente cuándo hay espacio para jugar o descansar.

## Fase 2: mejorar la personalización

1. Permitir cambiar colores de cada miembro desde la interfaz.
2. Añadir categorías visuales personalizables: dormir, comer, baño, cole, juego, transporte.
3. Permitir subir o escoger iconos propios por categoría.
4. Guardar los ajustes de visualización localmente para cada familia.

## Fase 3: reforzar la integración real

1. Sincronizar cambios periódicamente con Google Calendar.
2. Mejorar la detección de eventos duplicados o solapados.
3. Validar la consistencia de los datos importados en la vista de timeline.

## Fase 4: experiencia infantil

1. Añadir un modo niño más limpio, con botones grandes y muy pocos controles.
2. Mostrar una sola tarea principal en pantalla, con el siguiente paso destacado.
3. Permitir un modo de pantalla completa para tablet o TV.
